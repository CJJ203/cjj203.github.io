Attention 简介 先讲一些大家耳熟能详的概念。 Attention 根据 query 与 key 的相关性，对 value 做加权求和。Transformer 中，输入先经过线性投影得到 Q、K、V；对一个 head，计算为： $$ S=\frac{QK^\top}{\sqrt d}+M,\qquad P=\operatorname{softmax}(S),\qquad O=PV $$在 self-attention 中，$Q,K,V\in\mathbb{R}^{N\times d}$，$N$ 是序列长度，$d$ 是 head dim。$S_{ij}$ 表示第 $i$ 个 token 对第 $j$ 个 token 的注意力分数，softmax 沿 key 方向逐行计算。缩放因子 $1/\sqrt d$ 用于控制点积的数值范围。 语言模型通常采用 causal mask：$j\le i$ 时 $M_{ij}=0$，否则为 $-\infty$。位置 $i$ 只能读取自己和此前的 token。 下面是直接按公式写出的 PyTorch 实现。多头输入的形状为 [batch, heads, sequence, head_dim]，矩阵乘法在最后两个维度上进行： ...
